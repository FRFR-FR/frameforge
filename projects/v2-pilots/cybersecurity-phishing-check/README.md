# Cybersecurity pilot — Pause, Check, Verify, Report

**FrameForge V2 pilot · 12 seconds · 1280×720 · 24 FPS**

A defensive phishing-awareness animation with original editable SVG mock-interface elements. No real login page, credential capture, live suspicious URL, exploit instructions or third-party footage is included. The fictional sender uses a reserved .example domain.

## Visual treatment
This intentionally differs from the entertainment comparison: restrained cyan/red technical UI, a fictional message card, sender inspection, an independent verification flow and a report/delete checklist.

## Source-backed safety message
The advice is based on NIST phishing guidance and the CISA Secure Our World phishing tip sheet. Warning signs can include sender mismatches, urgency, unexpected links and attachments. A recipient should avoid acting on the message, verify using contact information or a website they already trust, and report it using the organisation's official process.

Sources:
- NIST, Phishing guidance: https://www.nist.gov/itl/smallbusinesscyber/guidance-topic/phishing
- CISA, Secure Our World: Phishing Tip Sheet: https://www.cisa.gov/sites/default/files/2024-09/Secure-Our-World-Phishing-Tip-Sheet.pdf
