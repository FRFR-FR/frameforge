Frame drawing script

Use the Canvas 2D API to draw detailed artwork.

JS
Your code runs locally. Use FF3D for lightweight mesh previews and camera tests. For production scenes with armature rigs, IK constraints, object properties, tracked cameras, full animation and CPU Cycles rendering, use the Blender production pipeline linked below. No generated images are required.
How to draw with code

The script receives ctx, frame (1-based), width, height, and time in seconds. It runs on a transparent layer above your hand-drawn artwork.

ctx.strokeStyle = "#e8b15b";
ctx.lineWidth = 5;
ctx.beginPath();
ctx.moveTo(80, 200);
ctx.bezierCurveTo(220, 80, 420, 340, 640, 150);
ctx.stroke();

Use Bézier curves, gradients, clipping, paths, and procedural texture for complex scenes. Only run code you trust.

Custom GLSL shader pass

WebGL 1 fragment shader. Required interface: varying vec2 v_uv; uniform sampler2D u_image; uniform float u_intensity. Preserve alpha in gl_FragColor.a. Compilation is tested at render time; invalid shaders fall back safely.

Reference video / creator format

34 · Narration-to-shot visual director

The draft splitter allocates the target duration across narration beats and suggests media from the chosen profile. Every beat remains editable; suggestions are not autonomous research or verified facts.

35 · Evidence, visual proof and rights review

Classify claims and cite source IDs. Only verified factual/comparative claims with sources can be attached to a shot marked as factual or comparative evidence. Illustrations and reconstructions must stay labelled as such.

Imported asset rights

Importing an asset does not establish ownership or reuse permission. Record the actual licence, permission or defensible review basis for each asset. This checklist does not determine legal rights.

Create a job to split your timeline into resumable frame chunks.
Render queue uses local IndexedDB. Close/reopen the page and resume a saved job; stored frames are skipped.

Each chunk ZIP contains numbered PNG frames and a manifest with resolution, FPS and frame range. Export each completed chunk, then merge the ZIP files with tools/merge_render_chunks.py before FFmpeg export. Keep separate backups of your imported media: the project JSON does not embed those files. Browser storage is quota-limited; pause if storage space is low.
